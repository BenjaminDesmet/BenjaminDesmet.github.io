02 Uitgelichte projecten

Eigen project · draait bij mij thuis

Dobiss MQTT Bridge voor Home Assistant

Een lichtgewicht .NET-service die een Dobiss-verlichtingssysteem (AmbiancePRO / EvolutionPRO) via TCP aanstuurt en de status van elke lamp publiceert op een MQTT-broker, zodat alles naadloos in Home Assistant verschijnt. Daarnaast is er een REST-API om lampen te bekijken, aan/uit te schakelen of te dimmen zonder MQTT. De bridge pollt de status op een instelbaar interval en draait als Docker-container.

  • .NET
  • TCP
  • MQTT
  • SlimMessageBus
  • Mediator
  • REST API
  • Docker
  • TUnit
  • Moq
  • Shouldly
  • GitHub Actions

Mobile Development · 2025 – 2026

BierBalans 🍺

Een .NET MAUI-app die je bewust maakt van de calorieën in je bier. Scan de barcode, de app zoekt het product op via Open Food Facts en logt het offline. Een geanimeerd bierglas loopt leeg naarmate je beweegt, dankzij een echte Strava-koppeling via OAuth. Met dagelijkse meldingen, grafieken van de laatste 14 dagen en schudden-om-te-verversen.
